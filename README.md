# marpテンプレート

> marpスライドのテンプレートです

## Requirements

- nodejs (npx)
- marp (>=4.0)

## Usage

1. `sample.md`を参考に、スライドのmarkdownファイルを作成する。
2. marpでスライドを生成する。

```bash
$ npx @marp-team/marp-cli --theme theme/fun.css --pdf sample.md --output sample.pdf
```
